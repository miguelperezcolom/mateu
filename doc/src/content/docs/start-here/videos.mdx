A series of short videos, each about one thing Mateu does. Every screen in them is a real Mateu app
running. Each episode is also embedded on the page of these docs it explains, so you can watch it
where you read about it. The whole series, in this order, is also a
[YouTube playlist](https://www.youtube.com/playlist?list=PLM7pCgzKt8fY).

New to Mateu? Start with episode 1, then follow the ones that match what you want to build.

## The series

### 1. Mateu in 3 minutes

What Mateu is: one model of the UI, declared once, rendered on the web, on phones and on the desktop.
More: [What is Mateu](/mateu-about/what-is-mateu/).

### 2. From a record to a full CRUD

screen customised. More: [AutoCrud](/java-user-manual/build/auto-orchestrators/).

<YouTube id="XgKnmx_5qFM" title="From a record to a full CRUD" />

### 3. No code at all

### 4. The same screen everywhere
