# zones

Pins the multi-column zoned form layout: `@Zones`/`@Zone` (Java), repeatable `[Zone]` (.NET) and `@zones(...)` (Python) must all emit one `ResponsiveGrid` (`stackBelow: 40rem`, so a narrow container stacks the zones) with one column per declared zone, each `@Section(zone=...)` card stacked inside its declared column. Each zone's width is a grid track; when EVERY zone is a percentage the tracks are emitted as `fr` (`64% 36%` → `64fr 36fr`), so declared widths that add up to 100% fit beside the column gap instead of overflowing the page by it. Worth pinning because the track rule and the section-distribution logic are duplicated by hand in all three backends (SectionFormRenderer.flushZonedRow/proportional, ReflectionMapper.BuildZones/ProportionalZoneTracks, mapper.build_zones/proportional_zone_tracks).
