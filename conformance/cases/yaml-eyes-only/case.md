# yaml-eyes-only

**Pins:** access keys on YAML components for an anonymous caller, applied server-side: an
`eyesOnly` field is not drawn, a `readOnlyUnless` field is drawn read-only, a `disabledUnless`
button is drawn disabled. (The case seeds no value for the hidden field: whether an AUTHORED route
seed of a hidden field travels in the state is left out — Java sends it.)
